## О проекте

Специализированная CRM/ERP-система для управления студией ландшафтного дизайна:
от первого обращения клиента до сервисного обслуживания сада через 3 года.

### Бизнес-процесс

1. **Лид** — форма с ФИО, контактами, адресом, кадастровым номером
2. **Замер** — анкета зонирования, инженерный аудит, фотофиксация
3. **Проектирование** — согласование концепций, рабочая документация
4. **Смета** — 4 блока: земляные работы, инженерия, озеленение, логистика
5. **Строительство** — Гант, ежедневные рапорты, фотоотчёты
6. **Сервис** — календарь садовода, ТО на 3 года

### Роли

| Роль | Кабинет |
|---|---|
| 👑 Владелец | Аналитика, ФОТ, права |
| 💼 Менеджер | Воронка, счета, договоры |
| 🎨 Дизайнер | Чертежи, дендроплан, ведомости |
| 🚜 Прораб | Гант, рапорты, табель |
| 🚚 Снабженец | Потребность, поставщики, логистика |
| 🤝 Клиент | Статус, согласование, дневник, камеры |

## Архитектура БД

- **Мультитенантность** через `tenant_id`
- **Мягкое удаление** (`deleted_at`)
- **Аудит** — `tm_audit_log`, `*_history`
- **Версионность** — сметы, концепции, документы
- **Гибридная схема** — старые поля + новые FK

### Ключевые сущности

- **Клиенты:** `tm_clients`, `tm_client_contacts`, `tm_client_briefs`
- **Проекты:** `tm_projects`, `tm_milestones`, `tm_project_members`
- **Задачи:** `tm_tasks`, `tm_task_dependencies`
- **Каталог:** `tm_catalog`, `tm_catalog_types`, `tm_catalog_variants`
- **Сметы:** `tm_estimates`, `tm_estimate_items`
- **Склад:** `tm_warehouses`, `tm_stock_items`, `tm_stock_movements`
- **Финансы:** `tm_invoices`, `tm_payments`, `tm_expenses`
- **Медиа:** `tm_media`, `tm_photo_reports`
