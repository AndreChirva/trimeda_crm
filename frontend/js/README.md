\# Frontend



HTML + CSS + JavaScript для интерфейса CRM/ERP.



\## Структура



\- `pages/` — страницы (дашборд, команда, проекты, клиенты, каталог)

\- `forms/` — формы (создание/редактирование/просмотр)

\- `css/` — стили

\- `js/` — скрипты



\## Дизайн-система



\- \*\*Основной цвет:\*\* `#2E7D32` (зелёный)

\- \*\*Акцент:\*\* `#4CAF50`

\- \*\*Фон:\*\* `#ffffff`, `#f8fafc`

\- \*\*Границы:\*\* `#e2e8f0`, `#cbd5e1`

\- \*\*Текст:\*\* `#1e293b`, `#64748b`

\- \*\*Скругления:\*\* 8–16px



\## Особенности



\- Адаптивность (grid + flex, media queries)

\- Премиум-карточки (градиенты, тени, hover)

\- Кастомные фильтры

\- Модальные окна

\- Маска дат (дд.мм.гггг)
