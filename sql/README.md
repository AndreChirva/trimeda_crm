\# SQL



Схема БД, индексы и хранимые процедуры CRM/ERP для ландшафтной студии.



\## Структура



\- `schema/` — CREATE TABLE для ключевых таблиц

\- `indexes/` — CREATE INDEX

\- `procedures/` — хранимые процедуры



\## Что показывает



\- Мультитенантность через `tenant\_id`

\- Мягкое удаление (`deleted\_at`)

\- Аудит и история изменений

\- Версионность (сметы, концепции, документы)

\- Динамические словари

\- Пагинация и фильтрация

\- Транзакции с TRY/CATCH
